1. tools/nightly/package.py. Usage: `package.py OUT FILE...`.
   - OUT must end in .tar.gz or .zip; otherwise print usage and exit 2.
   - Archive members go under the top directory snes2dhd/:
     - each FILE, by its base name;
     - <root>/LICENSE and <root>/NOTICE;
     - <root>/external/ares/LICENSE as licenses/ares-LICENSE.
   - A missing input or a duplicate base name → exit 1 naming it, with no archive written.
   - .tar.gz: tarfile "w:gz", keep mode bits (executables stay executable). .zip: zipfile ZIP_DEFLATED.
   - Create OUT's parent directory. Print `wrote <OUT> (<n> files)` and exit 0.
   - Put the logic in `package(out: Path, files: list[Path], root: Path) -> int`. main() passes root = the repo root (two parents up from the script), so tests can use a temp root.

2. tests/tools/test_package.py (unittest): use a temp root holding LICENSE, NOTICE and external/ares/LICENSE, plus two temp "binaries" (one chmod 755). Cover:
   - .tar.gz → exact member list, and the exec bit is kept;
   - .zip → exact member list;
   - a bad extension → exit 2;
   - a missing input → exit 1 and no archive.
