TASK: a minimal SDL3 window that shows the emulator's stock frames.

What already exists:
- CMakeLists.txt builds the static library snes2dhd_core and snes2dhd-headless. Binaries go to ${CMAKE_BINARY_DIR}. It already calls enable_testing() and find_package(Python3 ...).
- tests/headless/make_min_rom.py <out> writes a small test program (no game data) that fills the screen red.
- src/core/core.hpp (do not change it):
```cpp
namespace snes2dhd {
struct Frame { std::vector<std::uint32_t> pixels; std::uint32_t width = 0, height = 0; }; // XRGB8888, row-major, no padding
std::string load(const std::string& rom_path);   // "" on success, else an error message
const Frame& run_frame();                         // runs to the next frame and returns it
void unload();
}
```

Install SDL3 first. Fedora: `sudo dnf install SDL3-devel`. Ubuntu 25.04+: `sudo apt install libsdl3-dev`. MSYS2 CLANG64: `pacman -S mingw-w64-clang-x86_64-sdl3`.

src/frontend/main.cpp, usage `snes2dhd [--quit-after N] <rom>`:
- Bad command line → usage on stderr, exit 2. Load error → message on stderr, exit 1.
- `#include <SDL3/SDL_main.h>` (Windows entry point). SDL_Init(SDL_INIT_VIDEO).
- SDL_CreateWindowAndRenderer("snes2DHD", 768, 672, SDL_WINDOW_RESIZABLE, &window, &renderer).
- SDL_SetRenderVSync(renderer, 1) with `// shortcut: paced by vsync, wrong speed on non-60 Hz displays; upgrade to audio-driven pacing when audio lands`.
- A streaming texture: SDL_PIXELFORMAT_XRGB8888, SDL_TEXTUREACCESS_STREAMING, SDL_SetTextureScaleMode(tex, SDL_SCALEMODE_NEAREST). Recreate it whenever the frame size changes, and then call SDL_SetRenderLogicalPresentation(renderer, w, h, SDL_LOGICAL_PRESENTATION_LETTERBOX).
- Main loop: poll events (SDL_EVENT_QUIT ends the loop) → run_frame() → SDL_UpdateTexture(tex, nullptr, pixels, width*4) → SDL_RenderClear → SDL_RenderTexture(renderer, tex, nullptr, nullptr) → SDL_RenderPresent. With --quit-after N, leave the loop after N frames and exit 0.
- SDL3 calls return bool. On failure, print SDL_GetError() to stderr and exit 1. At the end, call unload() and SDL_Quit().

CMakeLists.txt (add only this):
- find_package(SDL3 REQUIRED CONFIG COMPONENTS SDL3); add_executable(snes2dhd src/frontend/main.cpp); link snes2dhd_core and SDL3::SDL3.
- A smoke test, using CTest fixtures:
