TASK: fetch open-licensed homebrew test ROMs, and check their frame hashes headlessly.

What already exists: `build/snes2dhd-headless --frames N <rom>` prints `frame <N> <W>x<H> sha256=<hex>` (exit 1 on a load error). The core supports only plain LoROM carts without coprocessors. CMakeLists.txt already calls enable_testing() and find_package(Python3 COMPONENTS Interpreter REQUIRED). build/ is gitignored.

1. Pick 1–3 ROMs. Each one must:
   - be a prebuilt .sfc/.smc file at a stable https URL, pinned to a commit or a release, not a branch;
   - come from a project whose LICENSE file covers the binary and is one of the allowed licences below;
   - be homebrew or a test ROM, with no commercial game content;
   - be plain LoROM with no coprocessor;
   - show a stable picture with no input. Choose frames after the picture settles (e.g. 300).
   Candidates to check yourself: SNES test-ROM repos on GitHub (for example undisbeliever's or PeterLemon's). Verify the licence yourself and skip any repo without a licence file. If none qualifies, stop and report. In the PR body, give for each ROM its source, its licence URL, and why it qualifies.

2. tools/roms/test-roms.json: a list of
   {"file": "x.sfc", "url": "https://...", "sha256": "<64 lowercase hex>", "license": "<SPDX id>", "license_url": "https://...", "source": "https://...", "frames": 300}

3. tools/roms/fetch_test_roms.py [--dest DIR] (default build/test-roms; paths relative to the repo root, two parents up from the script):
   - ALLOWED = {"0BSD","BSD-2-Clause","BSD-3-Clause","CC0-1.0","ISC","MIT","Unlicense","Zlib"}.
   - Check every entry before any download:
     - file matches ^[A-Za-z0-9._-]+\.(sfc|smc)$;
     - url and license_url start with https://;
     - license is in ALLOWED;
     - sha256 is 64 lowercase hex;
     - frames is an int from 1 to 3600.
     A failed check → exit 1, naming the entry.
   - If dest/file exists and its hash matches, print `ok <file>`.
   - Otherwise:
     - download with urllib.request.urlopen(url, timeout=60) and read at most 8 MiB + 1 bytes (more → fail);
     - check the SHA-256 (mismatch → fail, nothing written);
     - write to a temp file in dest, then os.replace it into place;
     - print `fetched <file>`.
   - `# shortcut: direct ROM URLs only, no archives; upgrade with zipfile when a needed ROM only ships zipped`.

4. tests/roms/check_frame_hashes.py --headless BIN --roms DIR --golden FILE [--manifest FILE] (manifest default tools/roms/test-roms.json):
   - Golden format: one `<file> <sha256>` per line. Blank lines and lines starting with # are ignored. A malformed line → exit 1.
   - For each manifest entry:
     - if the ROM is missing, exit 1 with "missing <file>: run tools/roms/fetch_test_roms.py first";
     - run [BIN, "--frames", str(frames), rom] and parse the sha256 from its output;
     - if it matches the golden, print `ok <file>`; otherwise print `FAIL <file>`.
   - At the end, print `frame hashes: <ok>/<total> ok`.
   - If anything failed, or the golden file is missing, print "golden lines for this build:" followed by the computed `<file> <sha256>` lines, and exit 1. Otherwise exit 0.
