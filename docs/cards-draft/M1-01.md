TASK: write a script that vendors the ares SNES core at a pinned commit.

Context: snes2DHD uses only the Super Famicom core of ares (https://github.com/ares-emulator/ares, ISC licence) and the support libraries it needs. The vendored copy will live in `external/ares/`. That path is protected: do NOT create or edit anything under external/. You write the script; the maintainer runs it and commits the result. Python ≥3.12, stdlib only.

1. tools/vendor/ares.json
   {"repo": "https://github.com/ares-emulator/ares.git",
    "commit": "<40 lowercase hex>",
    "paths": ["LICENSE", "ares/ares", "ares/component", "ares/sfc", "nall", "libco"]}
   - commit = the commit the newest ares release tag points to. Find it with
     `git ls-remote --tags https://github.com/ares-emulator/ares.git`. For an annotated tag, use the `^{}` line. Put the tag name and that ls-remote line in the PR body.
   - If any listed path does not exist at that commit, STOP. Report the output of `git ls-tree --name-only <commit>` and `git ls-tree --name-only <commit> ares/` instead of guessing.

2. tools/vendor/vendor_ares.py. Usage: `python3 tools/vendor/vendor_ares.py [--pin FILE] [--dest DIR]`. Defaults are tools/vendor/ares.json and external/ares, both relative to the repo root (two parents up from the script).
   - Check the pin. commit must be exactly 40 lowercase hex characters. paths must be a non-empty list of relative paths, with no ".." part and no leading "/". On a failed check, exit 1 with a clear message.
   - In a tempfile.TemporaryDirectory(): `git init -q`, `git fetch -q --depth 1 <repo> <commit>`, `git checkout -q FETCH_HEAD`. Use subprocess with list arguments and check=True.
   - Exit 1 if a listed path is missing, or if there is any symlink under a listed path (vendored code is untrusted input).
   - Delete DEST if it exists (shutil.rmtree). Copy each listed path to the same relative path under DEST. Never copy .git.
   - Write DEST/VENDORED.txt:
       repo: <repo>
       commit: <commit>
       paths: <space-separated paths>
       Generated by tools/vendor/vendor_ares.py. Do not edit files here; local changes go in patches/ares/.
   - Print exactly `vendored ares <commit> into <DEST> (<N> files)`, where N is the number of copied files (not counting VENDORED.txt), and exit 0.

3. tests/tools/test_vendor_ares.py (unittest, no network). In a temp dir, make a git repo with LICENSE, ares/sfc/a.cpp, nall/b.hpp and extra/skip.txt, and commit it. Write a temp pin with "repo": "file://<that path>", its real commit, and paths ["LICENSE","ares/sfc","nall"]. Run the script with subprocess and --pin/--dest. Check:
   - exit 0, the output line matches, extra/ is not copied, and VENDORED.txt contains the commit;
   - exit 1 for a bad commit string, a missing path, and a symlink inside a listed path.
   If git refuses to fetch by SHA from the temp repo, run `git config uploadpack.allowAnySHA1InWant true` in it.

Out of scope: patches, build files, NOTICE (it already names external/ares).
